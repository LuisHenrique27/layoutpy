# LAYOUTPY

LAYOUTPY gera interfaces em texto para terminal feito em python.

# Comandos
Exemplo:
```python
rect(50, 50, 200, 100)
```
| Parâmetro | Descrição            |
| --------- | -------------------- |
| `x`       | Posição horizontal   |
| `y`       | Posição vertical     |
| `w`       | Largura do retângulo |
| `h`       | Altura do retângulo  |

Saída:

```text
┌──────────────────────────────┐
│                              │
│        RETÂNGULO             │
│                              │
└──────────────────────────────┘
```
## Executando

Clone o projeto:

```bash
git clone https://github.com/LuisHenrique27/layoutpy.git
```

Entre na pasta:

```bash
cd layoutpy
```

Execute:

```bash
python main.py
```

## Ideia do projeto

O objetivo não é apenas desenhar formas, mas criar uma **linguagem gráfica simples**, onde as interfaces possam ser descritas através de comandos.
